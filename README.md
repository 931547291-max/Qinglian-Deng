# Qinglian-Deng Research Repository

This repository contains the code and data files for this study (hosted on GitHub: https://github.com/931547291-max/Qinglian-Deng). It encompasses resources such as land use data, environmental factors, and analysis scripts.

## 1. Root Directory Structure
The root directory contains data folders and raster data files:

### Folders (All labeled as "code and data files"):
- `CIM6/`
- `SICHUAN/`
- `code/`
- `sichuan-lucc/`

### Raster Data Files (.tif format):
- **Environmental Factors:**
  - `DEM.tif` (Digital Elevation Model)
  - `NDVI.tif` (Normalized Difference Vegetation Index)
  - `NPP.tif` (Net Primary Productivity)
  - `Railway.tif` (Railways)
  - `River.tif` (Rivers)
  - `Slope.tif` (Slope)

- **Socioeconomic Data:**
  - `gdp2019.tif.tif` (GDP for 2019)
  - `pop2019.tif.tif` (Population for 2019)

- **Climate and Soil Data:**
  - `pre2020.tif.tif` (Precipitation for 2020)
  - `soilType.tif.tif` (Soil Type)
  - `tem2020.tif.tif` (Temperature for 2020)

- **Transportation Data:**
  - `highway.tif` (Highways)
  - `national_highway.tif` (National Highways)

## 2. Subfolder Contents
- **`CIM6/` Folder:** Stores future climate data (e.g., precipitation, temperature)
- **`SICHUAN/` Folder:** Stores the vector boundary data for the study area
- **`sichuan-lucc/` Folder:** Stores Land Use and Land Cover Change (LUCC) data
- **`code/` Folder:** Stores analysis scripts

## 3. Code Description
- `Geographical Detector code.r`: Code for Geographical Detector analysis (R language)
- `Machine learning code surplus.py`: Machine learning analysis code (Python)

## 4. Usage
Clone the repository and ensure all dependencies are installed before running the scripts.
